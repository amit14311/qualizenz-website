🚀 How to Add Articles to Qualizenz

Three simple methods to manage your pharmaceutical knowledge content

METHOD 1️⃣: Edit HTML Directly (Easiest)

No coding experience needed. Just copy-paste!

✏️ STEPS:
  1. Open index.html with any text editor
  2. Find the blog section (search for "BLOG SECTION")
  3. Copy an existing blog card
  4. Paste it and edit the title, description
  5. Save the file
  6. Refresh your browser

🔍 Where to Find the Blog Section:

<!-- BLOG SECTION --> <section id="blog" class="blog-preview"> <div class="container"> <h2>Latest From Our Blog</h2> <div class="blog-grid"> <!-- YOUR ARTICLES GO HERE --> </div> </div> </section>

📋 Template to Copy-Paste:

<div class="blog-card"> <span class="blog-category">GMP</span> <h3>Your Article Title Here</h3> <p>Your 2-3 sentence summary goes here...</p> <div class="blog-meta"> <span>May 31, 2026</span> <a href="#" class="read-article">Read Article →</a> </div> </div>

✨ Example - Your First Article:

GMP

FDA GMP Requirements: Complete Guide 2026

The FDA Good Manufacturing Practices are fundamental regulations all pharmaceutical manufacturers must follow. This comprehensive guide covers facility design, equipment maintenance, and compliance strategies.

May 31, 2026 Read Article →

⏱️ Time: 2 minutes per article

METHOD 2️⃣: Use Python Script (Best for Bulk)

Add multiple articles automatically to your backend database

⚙️ REQUIREMENTS:
  • Python installed
  • pip install requests
  • python app.py running (backend server)

🔧 Setup Steps:

# Step 1: Install requests library pip install requests # Step 2: Create a file named add_articles.py # (Already created! Just use quick_add_articles.py) # Step 3: Start your backend server python app.py # Step 4: In another terminal, run: python quick_add_articles.py # Result: All 5 sample articles added! ✅

📝 Create Your Own Article Script:

import requests article = { "title": "Your Article Title", "content": "Full article content here...", "category": "GMP", "tags": ["tag1", "tag2"], "author": "Your Name" } response = requests.post( 'http://localhost:5000/api/articles/add', json=article ) print(response.json())

⏱️ Time: 1 minute for 10 articles

METHOD 3️⃣: Use API with CURL (Terminal)

Add articles directly from your terminal/command line

💻 Single Article:

curl -X POST http://localhost:5000/api/articles/add \ -H "Content-Type: application/json" \ -d '{ "title": "My Article Title", "content": "Article content...", "category": "Validation", "tags": ["validation", "qualification"] }'

📋 View All Articles:

curl http://localhost:5000/api/articles/list

⏱️ Time: 30 seconds per article
