# ⚡ QUICK REFERENCE: MANAGING QUALIZENZ WEBSITE

## 🎯 5-MINUTE QUICK START

### **FASTEST METHOD: HTML Edit**
```
1. Open: index.html (with notepad or VS Code)
2. Find: <!-- BLOG SECTION -->
3. Copy: An existing blog-card div
4. Paste: Below existing articles
5. Edit: title, description, date
6. Save: Ctrl+S
7. Refresh: Browser (F5)
Done! ✅
```

---

## 3 WAYS TO ADD ARTICLES

### METHOD 1: HTML (2 min/article) ⭐ RECOMMENDED FOR BEGINNERS
```
STEPS:
1. Open index.html in Notepad
2. Search for "blog-card"
3. Copy this structure:
   <div class="blog-card">
       <span class="blog-category">GMP</span>
       <h3>Your Title</h3>
       <p>Your summary</p>
   </div>
4. Paste 4 more times
5. Save (Ctrl+S)
6. Refresh browser (F5)
TIME: 10 minutes for 5 articles
```

### METHOD 2: Python Script (1 min/10 articles) ⭐ BEST FOR BULK
```
STEPS:
1. Terminal: pip install requests
2. Terminal: python app.py (start server)
3. Terminal: python quick_add_articles.py
TIME: 30 seconds for 5 articles
```

### METHOD 3: API CURL (30 sec/article) ⭐ FOR AUTOMATION
```
STEPS:
Terminal: curl -X POST http://localhost:5000/api/articles/add \
  -H "Content-Type: application/json" \
  -d '{"title":"...", "content":"...", "category":"GMP"}'
TIME: 2 minutes for 5 articles
```

## 💾 STORING ARTICLES

### LOCAL (Browser Storage - No Backend Needed)
```javascript
// In browser console:
// View articles
JSON.parse(localStorage.getItem('articles'))

// Add article
let articles = JSON.parse(localStorage.getItem('articles')) || [];
articles.push({title: "...", content: "...", category: "GMP"});
localStorage.setItem('articles', JSON.stringify(articles));
```

### DATABASE (Python Backend - Persistent)
```bash
python app.py
# Server at http://localhost:5000
# Data stored in ./data/articles.json
```

## ✍️ ARTICLE WRITING TIPS

### Title Format
```
Good: "FDA GMP Requirements: Complete Guide 2026"
Better: "FDA GMP Requirements: What Pharma Pros Need to Know"
Best: "FDA GMP Compliance: 7 Requirements Every Pharma Company Must Implement"
```

### Summary Length
- 2-3 sentences
- 50-100 words
- Include main keyword once

### Example Summary
```
"The FDA Good Manufacturing Practices (GMP) set minimum standards for pharmaceutical 
manufacturing. This guide covers the 7 core requirements, inspection focus areas, and 
how to ensure compliance. Learn what inspectors look for and avoid costly violations."
```
